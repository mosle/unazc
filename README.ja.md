# Unazc

[English](README.md) | 日本語

macOS (Apple Silicon) 用の日本語プッシュトゥトーク音声入力。Fn を押している間だけ録音し、離すとカーソル位置に文字が入ります。認識はすべて Mac の中で動きます。公開されている音声認識のモデルとエンジンを使っています（[謝辞](#謝辞)）。

<p align="center"><img src="docs/call-compact.png" width="266" alt="Unazc の電話画面（コンパクト）"><br><sub>おまけの電話画面（コンパクト表示）</sub></p>

## 特徴

- 離してから入力まで おおむね 0.1〜0.25 秒（M5 で実測）。話している途中は区切りごとに先に認識しておき、離した後は残りだけを処理します
- 話している間、カーソルの近くに認識途中の文字を表示（Mac の速さを起動時に測り、更新間隔を自動で決めます）
- フィラー除去や LLM による整形はしません。言ったとおりに入ります（貼り先が LLM であることを想定）
- 区切りの間で 「、」、「改行」「次の行」で改行、語尾の上がり調子で 「？」（いずれもオプション）
- よく間違える語を直す置き換え辞書（`wrong => right` の1行1件）
- 貼り付けはクリップボード経由ですが、元の内容は貼り先が読み終えてから戻します。クリップボード履歴アプリには残らない印を付けます
- 認識モデルはメニューで切り替え: ReazonSpeech（標準・最速）、ReazonSpeech 日英、Kotoba-Whisper（遅いが句読点付き）
- おまけ: 話の区切りで 「うん」「なるほど」と相槌を返したり、unazc と電話しているような画面を出したりできます（どちらも既定はオフ。音はイヤホンのときだけ）。名前の由来（うなずく）ですが、使わなくても上のとおり普通の音声入力です

IME ではありません。かな漢字変換の途中の状態とは独立に、確定した文字を貼り付けます。

## 必要なもの

- Apple Silicon の Mac、macOS 14 以降
- Xcode Command Line Tools（Swift 6）
- 約 2 GB の空き（モデル）

## ビルド

```sh
git clone https://github.com/mosle/unazc.git
cd unazc
sh scripts/fetch-deps.sh   # sherpa-onnx・whisper.cpp・モデルを取得
sh scripts/make-cert.sh    # 署名用の自己署名証明書「Unazc Dev」をログインキーチェーンに作成（初回のみ）
bash scripts/build-app.sh  # build/Unazc.app を作る
open build/Unazc.app
```

固定の証明書で署名するのは、再ビルドしてもマイクとアクセシビリティの許可が消えないようにするためです。証明書なしでも ad-hoc 署名でビルドできますが、その場合はビルドのたびに許可し直しになります。

モデルは `~/Library/Application Support/Unazc/models` に置かれ、チェックアウトの `models/` はそこへのリンクになります（~/Desktop や ~/Documents の中はアプリから読めないことがあるため）。

## 初回の許可

1. **マイク**: 起動時にダイアログが出ます
2. **アクセシビリティ**: システム設定 › プライバシーとセキュリティ › アクセシビリティ で Unazc をオンにします。Fn キーの検出と貼り付け（⌘V の送信）に必要です。許可すると再起動なしで使えるようになります
3. Fn キー単独で絵文字ピッカーや音声入力が開く設定になっている場合は、システム設定 › キーボード の「🌐キーを押して」を「何もしない」にしてください

## 使い方

| 操作 | 動作 |
|---|---|
| Fn を押し続けて話す | 録音。カーソル付近に途中の文字が出ます |
| Fn を離す | 認識した文字をカーソル位置に貼り付け |
| Fn を短く押す（設定で切り替え） | 「1回押して開始・もう1回で終了」か「両方」にすると、押して離しても録音が続き、次に Fn を押すと貼り付け（送信をオンにしていれば、Shift を押しながら Fn を押すと Enter も）。Esc で取り消し。録音を止める Fn 押下に V・Z・R・D を重ねても止まるだけです（使うときは止めた後に改めて Fn+キー） |
| 録音中に Esc | 取り消し |
| Fn+V | 直前の文字をもう一度貼る |
| Fn+Z | 直前の貼り付けを消す（貼った文字数ぶん Delete を送ります） |
| Fn+D | 置き換え辞書に登録する窓を開く（直前の文字が入っているので、間違えた部分だけに縮めて正しい文字を入れ、Enter。同じ文字の登録があれば上書き） |
| Fn+R | 直前の音声を別のモデルで認識し直して差し替え（ReazonSpeech ⇔ Kotoba-Whisper。初回はモデルの読み込みで数秒かかり、5分使わなければ解放） |

録音キーは Fn のほかに F13〜F19 も使えます。マクロパッドやプログラマブルキーボード（QMK / VIA など）のキーに F13〜F19 を割り当てて、録音ボタンにする想定です（オプション › 録音キー、複数選べます。上の表の Fn はどれでも同じ）。選んだ F キーはほかのアプリには届かなくなります。F20 はアプリ内部で使うため選べません。

Fn+Z と Fn+R は、貼った後に同じアプリでキー入力もクリックもしていないときだけ文字を消します。送信（Enter）済み、別の貼り付けの後、カーソルの直前が貼った文字と違う（アプリが Accessibility で教えてくれる場合）ときは、何も消さずに知らせます。直前の音声はメモリにだけ置き、ファイルには保存しません。

メニューバーのアイコンから:

- **認識モデル**: エンジンの切り替え
- **「（アプリ名）」での設定**: 前面のアプリだけの「、」「？」「改行」の設定（全体の設定に従う／オン／オフ）。録音を始めたときに前面にあったアプリの設定で文字を作ります。設定画面の「アプリ別」タブでも一覧・変更・削除できます
- **設定…**（⌘,）: すべての設定を1つの画面で変えられます（下のオプションと同じもの＋相槌の音量）。電話画面を右クリックしても開けます
- **オプション**: 途中表示、区切りの 「、」、「？」、話して改行、貼り付け後に Enter（自動送信）、録音キー（Fn・F13〜F19）、録音キーの使い方（押している間／1回押して開始・終了／両方）、マイクを開いたままにする時間、録音を終えた後の延長、録音中は音楽や動画を一時停止、間で相槌を返す、電話画面（コンパクト・常に前面・不透明度）
- **ログイン時に起動・落ちたら自動で再起動**: `~/Library/LaunchAgents/io.github.mosle.unazc.plist` を置き、launchd に管理させます。落ちた（クラッシュした）ときだけ再起動し、メニューの「終了」では止まったままです。起動して30秒以内に落ちることが2回続いたら、それ以上は再起動しません（手で開くか次のログインで再開）。メニューでオフにすると次のログインからは起動しません。動いているアプリはそのまま使え、ログアウトするまではクラッシュしたときの再起動も続きます
- **直前の文字を辞書に登録…**: Fn+D と同じ
- **置き換え辞書を編集…**: `~/Library/Application Support/Unazc/vocab.txt` を開きます。保存すると次の発話から効きます
- **ログを開く**: `~/Library/Logs/Unazc/unazc.log`（処理時間と認識結果の文字を記録します。音声は保存しません）

「録音中は音楽や動画を一時停止」（既定はオフ）は、録音を始めたときに他のアプリが音を出していれば再生／一時停止キーを1回送り、録音が終わったらもう1回送って再開します。macOS 14.2 以降で動きます。macOS 15.4 以降はアプリから「いま再生中か」を尋ねられないため、音が出ているかで判断しています。そのため、一時停止しても音声出力を握ったままのアプリや通話アプリが音を出しているときは、止める代わりに再生を始めてしまうことがあります。

### 相槌（おまけ・実験的・既定はオフ）

音声入力そのものには関係ない、好みで足す機能です。オフのままでも何も変わりません。黙ってから約0.25秒で、話している途中の文字と語尾の上がり方から選んで鳴らします。人の相槌よりは粗めです。

「間で相槌を返す」をオンにすると、話している途中の区切りで短い相槌が耳に返ってきます。語尾が上がれば 「うん」「うーん」、長く話したあとは 「なるほど」 のように選び、毎回は返しません。マイクが拾って文字になってしまわないよう、出力がイヤホン（ヘッドホン端子・Bluetooth・USB）のときだけ鳴らします。ただし Bluetooth や USB のスピーカーはイヤホンと区別できないので、スピーカーで聞くときはオフにしてください。

音は Gemini TTS で作ったものを同梱しています（[Resources/backchannel](Resources/backchannel/README.md)）。`~/Library/Application Support/Unazc/backchannel` に音声を置けば、別の声や自分の録音に替えられます。

### 電話画面（おまけ・実験的・既定はオフ）

「電話画面を出す」をオンにすると、unazc と通話しているような小さな画面が出ます。Fn を押している間は相手が聞いている表示になり、区切りでうなずきます（相槌の音と同じ判定。スピーカーのときも、うなずきは見えます）。赤いボタンで閉じます。

- ドラッグで好きな位置に置けます（位置は覚えます）
- 「電話画面をコンパクトに」: アイコン・名前・電話を切るボタンだけの細い1行にします
- 「電話画面を常に前面に」: 他のウィンドウより上に、どのデスクトップにも出します。オフなら普通のウィンドウと同じ重なり方です
- 「電話画面の不透明度」: 100%〜30%（設定画面ではスライダーで細かく）
- 右クリックで 設定… / コンパクト表示 / 常に前面に / 不透明度 / 電話を切る
- 画面はフォーカスを取らないので、クリックしても文字の入力先は変わりません

```sh
swift test   # 音声・キー入力・モデルを使わない部分（区切りのつなぎ方、置き換え辞書、語尾の上がり判定、貼り付けの手順など）
```

## コマンドライン

アプリ本体の実行ファイルは調整用のコマンドも兼ねます（`.build/release/Unazc` または `build/Unazc.app/Contents/MacOS/Unazc`）。

```sh
Unazc --transcribe <audio> [sherpaModelDir]   # 音声ファイルを認識
Unazc --segmented <audio>       # 区切りごとの認識（アプリと同じ処理）
Unazc --replace <text> [file]   # 置き換え辞書を試す
Unazc --intonation <audio...>   # 語尾の上がり具合（半音）
Unazc --speed                   # この Mac での途中表示の更新間隔
Unazc --login-agent on|off|status   # off は launchd が動かしているアプリも止めます
```

`UNAZC_ENGINE=reazon|reazonJaEn|kotoba` でエンジンを、`UNAZC_THREADS` でスレッド数を指定できます。

Unazc は以下のモデルとソフトウェアを使っています。公開してくださっている皆さんに感謝します。

| | ライセンス | 入手 |
|---|---|---|
| [sherpa-onnx](https://github.com/k2-fsa/sherpa-onnx) | Apache-2.0 | `fetch-deps.sh`。C API のヘッダ `Sources/CSherpaOnnx/include/c-api.h` は同梱（未改変） |
| [whisper.cpp](https://github.com/ggml-org/whisper.cpp) | MIT | `fetch-deps.sh` |
| [ReazonSpeech zipformer](https://k2-fsa.github.io/sherpa/onnx/pretrained_models/offline-transducer/zipformer-transducer-models.html)（sherpa-onnx 版） | 配布元を参照 | `fetch-deps.sh` |
| [Kotoba-Whisper v2.0](https://huggingface.co/kotoba-tech/kotoba-whisper-v2.0-ggml) | 配布元を参照 | `fetch-deps.sh` |
| [Silero VAD](https://github.com/snakers4/silero-vad) | MIT | `fetch-deps.sh` |

同梱の相槌の音声は Gemini TTS で生成したもので、MIT ライセンスの対象外です（権利は主張しません。[詳細](Resources/backchannel/README.md)）。

モデルはこのリポジトリに含まれず、ビルド時に各配布元から取得します。利用条件は各配布元に従ってください。
